Mathematical Logic

1. Age-Based Water Goal

Age group determines the suggested daily target:

4–8 years = 1,200 ml
9–13 years = 1,700 ml
14–64 years = 2,000–2,500 ml
65+ years = 1,700–2,000 ml

2. Custom Goal Validation

Daily Goal = User's Chosen Target
Valid goal: 250 ml ≤ Goal ≤ 10,000 ml

3. Log Water

New Total = Previous Total + Water Added
Example: 500 + 250 = 750 ml
Valid entry: 0 ml < Amount ≤ 5,000 ml

4. Remaining Water

Remaining = Daily Goal − Total Consumed
2,000 − 1,250 = 750 ml remaining
Remaining cannot be less than 0 ml.

5. Progress Percentage

Progress = (Total Consumed ÷ Daily Goal) × 100
(1,500 ÷ 2,000) × 100 = 75%
Maximum displayed progress = 100%

6. Water Bottle Progress

Bottle Fill (%) = Progress (%)
1,000 ÷ 2,000 × 100 = 50% full

7. Mascot Feedback

Progress < 75% → Encouragement
75% ≤ Progress < 100% → Motivation
Progress ≥ 100% → Celebration

8. Reset Progress

Total Consumed = 0 ml
Progress = (0 ÷ Daily Goal) × 100 = 0%

9. Reminders

Next Reminder = Last Reminder + Interval
10:00 AM + 1 hour = 11:00 AM
Show reminder when enabled and due.

10. Save User Data

Saved Data = Age + Goal + Water Total + Reminder Settings

11. New-Day Reset

If Current Date ≠ Saved Date:
Total Consumed = 0 ml

12. Goal Completion

Total Consumed < Goal → Incomplete
Total Consumed ≥ Goal → Complete
Example: 2,000 ml ≥ 2,000 ml → Complete

13. Error Handling

0 ml < Water Entry ≤ 5,000 ml → Accept
250 ml ≤ Daily Goal ≤ 10,000 ml → Accept
Outside either range → Show Error
